BCS Word Trainer - Android project

OPTION A - Android Studio (on your computer)
1. Install Android Studio and Node.js.
2. Unzip this folder, open a terminal inside it and run:  npm install
3. Run:  npx cap sync android
4. Run:  npx cap open android
5. In Android Studio: Build > Build APK(s). The APK appears in android/app/build/outputs/apk/debug/

OPTION B - GitHub (no installs)
1. Create a free GitHub repository and upload everything in this folder
   (including the hidden .github folder).
2. Open the Actions tab > "Build APK" > wait for it to finish.
3. Download "BCS_Word_Trainer_apk" from the run page and unzip it to get app-debug.apk.

Install: copy app-debug.apk to your phone, open it, and allow "install unknown apps" when asked.
Progress is saved on the phone automatically. Use Progress > Download backup to keep a copy.
